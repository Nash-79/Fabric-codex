# Search

The **Search** page searches the whole knowledge base from one box. Type a query and press
**Search** (or Enter) — results are grouped into:

- **Topics** — names and descriptions in the topic tree.
- **Articles** — this group includes articles, designs, and lessons together: any piece of
  content whose title, summary, or body matches.
- **Claims** — the atomic facts themselves, each shown with its depth, capability, and
  source link.
- **Sources** — titles and reader summaries of approved sources.

Each group shows its match count. Clicking a topic opens the topic page; clicking a claim
takes you straight to the source URL; clicking a source opens the source URL in a new tab.

## What search reflects

Search only returns **published, active** content and **active** sources and topics —
superseded versions and archived content never appear. Search does not currently support
filtering by kind or by tag from the results page; it is a single combined query across
topics, content, claims, and sources.
